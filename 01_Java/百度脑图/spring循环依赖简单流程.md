# spring循环依赖简单流程

- 获取bean
  - bean工厂
    - bean仓库/单例池
- 创建Bean
  - 单例池找有就返回
  - 单例池没有就创建
    - 实例化
      - 填充属性
        - 初始化
          - 放到单例池并返回
- spring三级缓存解决循环依赖，和aop代理
  - 单例池，半成品池，工厂池
- bean生命周期
  - 通过构造器创建bean实例(无参构造)
    - 为bean的属性设置值和对其他bean引用(掉用set方法)
      - 调用bean的初始化的方法(需要进行配置)
        - bean可以使用了(对象获取到了)
          - 当容器关闭时候，滴哦阿勇bean的销毁的方法(需要进行配置)
        - 把bean实例传递bean后置处理器的方法
      - 把bean实例传递bean后置处理器的方法
