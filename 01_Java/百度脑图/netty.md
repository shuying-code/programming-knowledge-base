# netty

- nio基础
  - Channel
    - FileChannel
      - 文件传输通道
    - DatagramChannel
      - udp网络编程时的通道
    - socketChannel
      - tcp数据传输的通道
    - ServerSocketChannel
      - 服务端tcp数据传输的通道
  - Buffer
    - ByteBuffer
      - MappedByteBuffer
      - DirectByteBuffer（直接内存不会堆垃圾回收受到影响）分配内存效率低
      - HeapByteBuffer（堆内存受到垃圾回收的影响）
    - shortBuffer
    - IntBuffer
    - LongBuffer
    - DoubleBuffer
    - charBuffer
  - selector
    - （多线程版）多客户端时候每个客户端连接创建 一个线程服务器端内存占用高线程的上下文切换成本高 等
    - （线程池版）在阻塞模式下，在统一时间每个线程只能 处理一个操作，仅适合短连接连接场景比如http
- netty组件
  - EventLoop
