# База знаний по программированию (Java / Go / Rust)

> Персональная база знаний для бэкенд-разработчиков, организованная по трём направлениям: **Java / Go / Rust**. Содержимое — в основном **документы Markdown** (к каждому прилагается одноимённый Word `.docx`), а также интеллект-карты Baidu и примеры проектов. PDF-книги не включены в репозиторий по причине размера и авторских прав (см. [Список книг](<00_索引/书籍清单.md>)).

## Рекомендуемый порядок изучения

- **Систематическое повторение**: сначала прочитайте «Конспекты» соответствующего направления → затем проверьте себя по «Вопросам для собеседования» → в конце закрепите на практике с «Руководством по фреймворкам» (в Rust можно запустить пример проекта).
- **Подготовка к собеседованию**: сразу читайте «Вопросы для собеседования (избранное)», а при пробелах возвращайтесь к соответствующей главе «Конспектов».
- **Обзор по картам**: для Java начните с [плана интеллект-карт Baidu](<01_Java/百度脑图/README.md>), чтобы построить общую картину.

## Соглашения по именованию и формату

- Каждое направление единообразно содержит три типа документов: `<направление> Конспекты (обработанные)`, `<направление> Вопросы для собеседования (избранное)`, `<направление> Популярные фреймворки и практическое руководство` (в Java вместо руководства по фреймворкам используется «План интеллект-карт Baidu»).
- Все документы доступны в двух форматах: `.md` (онлайн-чтение) и `.docx` (скачивание и редактирование).
- Поскольку лимит предпросмотра одного файла в GitHub составляет около 100 КБ, слишком большие сборники разбиты по темам (например, сборник интеллект-карт Baidu разделён на тома 1/2/3).
- Дублирующееся содержимое удалено: все отдельные `.md`-конспекты карт Baidu объединены в 3 тома; 21 исходный `.km` объединён в единый `百度脑图思维导图合集.km`.

## Отказ от ответственности

Содержимое этого репозитория предназначено только для личного изучения и обмена; авторские права на книги принадлежат их авторам и издательствам. Материалы являются личными учебными конспектами и неизбежно содержат упущения — исправления приветствуются.
