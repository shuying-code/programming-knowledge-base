- **体系的復習**：対応する方向の「知識ノート集」→「面接問題」で確認 → 最後に「フレームワークと実践ガイド」で実践（Rust はサンプルプロジェクトを実行可能）。
- **面接対策**：「面接問題（精選版）」を直接読み、盲点があれば「知識ノート集」の該当章に戻る。
- **マインドマップで概観**：Java はまず [Baidu マインドマップ概要](<01_Java/百度脑图/README.md>) で全体像を把握。

## 命名とフォーマットの規約

- 各方向は 3 種類のドキュメントに統一：`<方向>知識ノート集（整理版）`、`<方向>面接問題（精選版）`、`<方向>常用フレームワークと実践ガイド`（Java は「Baidu マインドマップ概要」でフレームワークガイドを代替）。
- すべてのドキュメントは `.md`（オンライン閲覧）と `.docx`（ダウンロード・編集）の両形式を提供。
- GitHub の単一ファイルプレビュー上限が約 100 KB のため、大きすぎる合集はテーマ別に分割（例：Baidu マインドマップ合集は「一 / 二 / 三」冊に分割）。
- 重複内容を削除済み：Baidu マインドマップの各 `.md` 概要はすべて 3 冊の合集に統合。21 個の元 `.km` は単一の `百度脑图思维导图合集.km` に統合。
