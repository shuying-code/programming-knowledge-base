# 编程知识库 · 用户操作手册

> 适用对象：使用本知识库进行学习、复习或面试准备的开发者。
> 本手册介绍如何浏览仓库、阅读三种文件格式、按路径高效学习、打开百度脑图、运行示例项目与常见问题。
> 仓库总览见根目录 [README](../README.md)，文件清单见 [知识库索引](知识库索引.md)。

---

## 1. 这个知识库是什么

一个面向后端开发的个人知识库，按 **Java / Go / Rust** 三大方向整理，内容以 **Markdown** 为主（每份附同名 `.docx`），并包含百度脑图思维导图与 Rust 示例项目。书籍 PDF 因体积/版权不随仓库提供（见 [书籍清单](书籍清单.md)）。

---

## 3. 三种文件格式与打开方式

| 格式 | 用途 | 如何打开 |
|---|---|---|
| `.md` | 在线阅读 / 检索（推荐先看） | GitHub 网页直接预览；或任意 Markdown 编辑器（VS Code、Typora、Obsidian） |
| `.docx` | 下载后编辑 / 打印 | Microsoft Word、WPS |
| `.km` | 百度脑图源文件（可继续编辑） | 在 <https://naotu.baidu.com> 导入打开（见第 5 节） |

> 因 GitHub 单文件预览上限约 100 KB，过大的合集已按主题拆分（如百度脑图合集分为「一 / 二 / 三」册）。

## 4. 推荐阅读路径

- **系统复习**：先读对应方向的「知识笔记合集（整理版）」→ 再用「面试题（精编版）」自测 → 最后看「常用框架与实战指南」落地（Rust 可运行示例项目）。
- **面试突击**：直接看「面试题（精编版）」，遇到盲区回到对应方向的「知识笔记合集」相关章节。
- **脑图速览（Java）**：先看 [百度脑图大纲](../01_Java/百度脑图/README.md) 建立整体框架，再深入细节。

---

## 5. 打开百度脑图（.km）

1. 浏览器打开 <https://naotu.baidu.com>。
2. 选择「打开 → 导入」，选中 `01_Java/百度脑图/百度脑图思维导图合集.km`。
3. 导入后可在线查看/编辑，也可导出为图片或其他格式。

> 若只想快速浏览，可直接阅读已导出的大纲 `.md` / `.docx`（百度脑图合集一/二/三）。

## 6. 运行 Rust 示例项目

示例项目位于 `03_Rust/示例项目/axum-todo-api`（Axum 0.8 + Tokio 最小 REST API）：

```bash
cd 03_Rust/示例项目/axum-todo-api
cargo run
# 默认监听本地端口，可用 curl / 浏览器访问其路由
```

需要本机已安装 Rust 工具链（`rustup`）。

## 7. 下载与离线阅读

- 单份文档：在 GitHub 打开文件后点「Download raw file」，或使用「Code → Download ZIP」下载整仓。
- 克隆仓库：

```bash
git clone https://github.com/shuying-code/programming-knowledge-base.git
```

- 离线时 `.md` 用本地 Markdown 编辑器打开、`.docx` 用 Word/WPS 打开均可。

## 9. 常见问题（FAQ）

**Q：为什么仓库里没有书籍 PDF？**
PDF 体积大且涉及版权，本仓库不托管；完整书单见 [书籍清单](书籍清单.md)。

**Q：`.docx` 和 `.md` 内容一样吗？**
一样，`.docx` 由 `.md` 导出，便于编辑与打印，建议优先读 `.md`。

**Q：怎么快速找到某个主题？**
用 GitHub 仓库页搜索框，或打开对应方向的「知识笔记合集」按章节浏览；也可用 `知识库清单.csv` 查文件。

**Q：可以用于面试准备吗？**
可以，按第 4 节「面试突击」路径学习即可。
