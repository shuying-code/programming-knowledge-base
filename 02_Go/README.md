# 02_Go（Go 方向）

Go 学习资料整理。内容参照 Go 官方文档、Effective Go、Go by Example 及 Gin / GORM / go-zero 等主流框架文档整理（面向 Go 1.22+，当前最新为 go1.27）。

## 文档

- [Go 知识笔记合集（整理版）](<Go知识笔记合集（整理版）.md>) — 17 章：语言特点与面向对象、基础语法、高频问答、Slice、Map、接口、Context、Channel、GMP、锁、并发控制、内存与逃逸、GC、编译与工程、框架生态、排查场景。
- [Go 面试题（精编版）](<Go面试题（精编版）.md>) — 49 道高频问答 + 7 道「能否编译/输出」代码题，覆盖基础、数据类型、接口、并发、GMP/GC、错误处理、工程化、性能排查。
- [Go 常用框架与实战指南](<Go常用框架与实战指南.md>) — net/http 与优雅停机、Gin、Echo、GORM、go-zero、配置/日志/依赖注入、测试与 pprof、并发实战模式、项目结构与部署。
- 以上三份文档均附同名 `.docx` Word 版本。

## 说明

- 面向有 Java 等后端基础、希望系统掌握 Go 的开发者，按「语言 → 并发 → 工程化 → 实战」组织。
- 后续可继续补充：Go 书籍 PDF、Gin/go-zero 完整示例项目、微服务实战。
